# Workflow de Revisão de Capítulos

Este workflow define o processo padrão para revisar capítulos, garantindo consistência narrativa e qualidade estética.

## 1. Preparação
- [ ] Ler `GEMINI.md` para alinhar com o tom (Noir/Cyberpunk) e regras do universo.
- [ ] Ler `docs/personagens.md` para verificar fichas de personagens.
- [ ] Ler `docs/ranking_qualidade_capitulos.md` para entender o padrão de notas.

## 2. Critérios de Análise
Ao ler cada capítulo, verificar:
- **Lore & Universo:**
  - Atmosfera "High Tech, Low Life" (Chuva, Neon, Sujeira).
  - A tecnologia é opressora?
  - A moralidade é cinzenta?
- **Elementos de Gênero:**
  - Há investigação, tensão, tiroteio ou perseguição?
  - O ritmo é adequado?
- **Personagens:**
  - Gabo fuma? (NÃO PODE). Ele toma café? (SIM).
  - Valéria é "tech-sidekick"?
  - As vozes dos personagens são distintas?
  - Há equilíbrio na participação?
- **Continuidade:**
  - O capítulo se conecta logicamente com o anterior e o posterior?
  - Detalhes (ferimentos, itens) são consistentes?

## 3. Ações de Consolidação
Para cada capítulo revisado:
1.  **Atribuir Nota (1-10).**
2.  **Listar Pontos Fortes e Fracos.**
3.  **Atualizar `docs/ranking_qualidade_capitulos.md`:** Inserir a análise no formato padrão.
4.  **Atualizar `docs/personagens.md`:** Se houver mudança visual, idade ou evento marcante na linha do tempo.
5.  **Atualizar Checklist:** Marcar como concluído no sistema de tarefas.

## 4. Estilo de Escrita
- Manter o tom cínico e "snappy" nas observações.
- Focar no impacto emocional ("O que o leitor sente?").
